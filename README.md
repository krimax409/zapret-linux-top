# zapret-linux-top

Экспериментальная Linux-обёртка над `nfqws` с TUI и поддержкой стратегий
[zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube).

## Запуск

```bash
sudo ./zapret.sh
```

При первом запуске стратегии и служебные файлы скачиваются автоматически.

Сейчас проект ориентирован на NixOS. Поддержка других дистрибутивов и нового
формата стратегий Flowseal находится в разработке.
